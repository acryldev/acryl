01 · Repository roles

Four directories, four different responsibilities

Pinned source

deepseek-harness/

Read-only upstream source and pnpm workspace. It is not loaded as one plugin; published @deepseek-ai/dsh-* packages provide the runtime rows.

Executable

acryl-desktop/

Electron launcher plus ordinary Cordis Host/Client plugins, package exports, native adapters, profile composition, lifecycle, recovery, and packaging.

Optional provider

dsh-community-market/

Implemented Host and Client entries. Disabled by default; selecting it inserts one provider row and enables managed bundle inventory.

Documentation only

dsh-community-fabric/

Interoperability RFCs only. No exports, bundle patch, schema release, SDK, Loader row, or Fiber.

05 · Market boundary

Discovery and activation remain separate

Provider selection

Fresh state is disabled. Selecting Community Market adds community-market → dsh-community-market. The alternative is dsh-market → dshmarket.

Catalog providers

Reviewed built-in adapters exist for DSH 1024Store and dshfind. Users must add and select a source; standard contract-compatible HTTP sources are also supported.

Installed inventory

When Community Market is active, desktopPlugins inventories direct profile bundles and supports two-phase enable/disable operations.

Trust statement

A listing is untrusted remote metadata. Install preview and execution perform separate checks; installed plugins still execute as local code with user authority.
