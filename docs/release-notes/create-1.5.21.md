# create-acrylblends 1.5.21

Released with [acrylblends 1.5.21](acrylblends-1.5.21.md). An app made from a repository (`--from github:owner/repo#tag`, such as a community Blend) is its new owner's, as one made from a registry id: its own id, `visibility: private` and no `license` line. The starter's LICENSE file stays beside it as `STARTER-LICENSE`, since its terms ask for the notice to be kept.
