## ACRYL 0.3.8: `acryl new` shares one install too

- **An app you make with `acryl new` now costs about 7-18 MB instead of about 700 MB.** Since 0.3.7, apps made in ACRYL Control Center
  start from the one install of their Blends version, kept once in `~/.acryl/program`. `acryl new <name> [starter]` in a terminal now
  does the same: it makes the app, installs it from that shared install, and starts it as before.
- Measured on macOS, Windows and Ubuntu, three apps each. After the first app, each one took 6.7-6.9 MB on Ubuntu, 8.6-11.3 MB on
  Windows and about 18 MB of free space on macOS, with Electron on disk once for all of them. Every app started, opened its window, ran
  its terminal and picked up a new plugin live.
- The first app you make on a Blends version installs in full, as before; it becomes the shared install for the ones after it.
- Unchanged: an app made from another source (`--from`, a GitHub repository, an npm package, a folder) or with `--install`, `--no-install`
  or `--pm` is installed by `create-acrylblends` exactly as before. So is `npm create acrylblends` without `acryl`.
