## ACRYL 0.3.9: give the space back

- **`acryl apps reinstall [<app>]` moves an app onto the one shared install.** An app made before 0.3.7 carries its own full copy of
  the framework, about 400 MB. Reinstalling it keeps the app's own files and data as they are, replaces only its packages, and starts it
  from the shared install, kept once in `~/.acryl/program`. Measured on Ubuntu, Windows and macOS: each reinstalled app gave back 356-412 MB.
  If the install fails, the app keeps the packages it had. Without an app name it reinstalls every app in your list.
- **`acryl clean` removes the shared installs no app uses any more.** It lists each folder it would remove and how much space that gives
  back, asks once, and removes nothing else: never an app's own files or data. In a script, `acryl clean --yes` removes them without asking.
  On macOS it says "up to", because apps made from a shared install keep part of its space.
- Stop an app before you reinstall it. On Windows a running app cannot be reinstalled, and on macOS and Linux it should be restarted afterwards.
