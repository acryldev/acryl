ACRYL: one place for every app on this machine

The launcher grows into a local app store, launchpad and maintainer for every app made with ACRYL, by people or by their agents. The fixed app in /Applications stays stable; everything that changes lives in ~/.acryl and in the app folders, and this screen is how a person sees it, opens it and keeps it healthy. The screen is called just "ACRYL": the desktop app is ACRYL, and it launches everything ACRYL can do.

"with launcher ACRYL it can become kind of a local App-store for all local apps built by acryl platform and agents, ad-hoc use cases launchpad, launcher and maintainer, operating Control Center Dashboard" (owner, 2026-11-12). Decided the same day: the screen is just "ACRYL", not "Control Center".

The problem it solves

A normal app is one thing in /Applications that never changes by itself. ACRYL is split in two: a fixed part that rarely changes, and a changing part that grows every day as people and agents make apps. Without a front door for the changing part, people do not know what they have or how to open it.

How the list stays true

Made

acryl new, the store, and an agent that builds an app add one line to ~/.acryl/apps.json: id, path, Blend, who made it. An agent adds its line only when it asks to keep the app.

Found

"Add a folder" adds any folder with a blend.yaml. Nothing scans the disk by itself.

Checked

On open, each entry is checked: folder still there, running or not (its port), update waiting (registry index).

Acted on

Every button runs an existing command (npm run dev, acryl update, acryl deploy, plugin publish), shown before it runs.

Decided (owner, 2026-11-12)

The screen is called "ACRYL"

It is the desktop app ACRYL, which launches everything ACRYL can do. On acryl.dev the page is laid out like the install pages of Hermes and OpenClaw (hermes-agent.nousresearch.com/#install, openclaw.ai/install).

Agent apps: only when the agent asks

The user first chooses where an app lives; the default is a folder in the home folder (~/ACRYL). When an app joins the daily flow it can be moved to /Applications/<name>.

New apps: ask each time

The question suggests ~/ACRYL, a visible folder (the hidden ~/.acryl keeps ACRYL's own records). The user can type any other place.
