Spec 056 · design · study bs44uxui

A prompt-first app builder with a three-pane workspace and a second life as a personal agent

The product is a web app builder in two halves. The builder half starts on a single home question ("Hi there. What will you build next?") with one prompt box and a Build / Auto mode control; an app then opens into a three-pane workspace: agent chat on the left, a canvas in the middle, app navigation and an admin dashboard on the right, with Preview, Dashboard and Edit modes, in-place text editing on the canvas, a chat branch popover, a version history with a Live marker, a theme picker that sends its choice to the chat, a Publish button with a public URL and a Connect domain step, and a Templates gallery to start from. The agent half is a separate Agent mode with its own rail: a first-run routine setup, one conversation list, chat started from the web, a messaging app, or a phone channel, scheduled and triggered Workflows, Plugins (connectors and skills), Notes, Files, Memory with source filters, and Data tables. Around both sit workspace areas: an Apps list, Templates, a code environment that connects GitHub, a Connectors list, a community map with events, a weekly launch leaderboard, and a partner marketplace with direct messages. Credits and Upgrade sit inside the working surfaces, and the builder treats plan limits as an answer the agent can give.

Method: 25 screenshots from the owner's private research folder, read in full and redrawn here in neutral styling with HTML and CSS, using the light and dark tokens of spec 052's AOS mockup. No screenshot is embedded. Names of people, companies, apps, notes and URLs are illustrative replacements; the studied product's name, brand, colors and logo appear nowhere. Source file names in the coverage list are shown with the product token replaced by <product>. Product states that the screenshots do not show are marked "not in the screens".

24. Take for ACRYL, do not take, and why

Pattern in the screensTake for ACRYLDo not takeWhy
Home startOne prompt box with a visible mode control (Auto, Build)Community, Partners and a template marketplace in the main railOne clear start. Marketplaces pull focus from making.
Workspace layoutThree panes: chat, canvas, app navigation or right panel16 flat navigation items with New badgesThe frame already has three panes. Generated areas need groups, not a wall.
ModesPreview, Dashboard, Edit, with phone and tablet widthsA light home and a dark workspaceExplicit modes fit one canvas. Theme should follow the user, not the area.
Direct editSelect text on the canvas with a small toolbar; agent proposals with Approve and RejectA theme choice that can only apply through Send to chatDirect manipulation is faster. Chat stays an option, not a toll gate.
VersionsHistory with a Live marker and a per-version menuVersion titles like Manual Edits with no diff or summaryA version must say what changed.
BranchesA one-line branch popover in the chat headerA branch feature with no merge example in sightExplain advanced work where it happens.
PublishPublish at top right, with the public URL and Connect domain beside itUpgrade in the top bar of every screenShipping is the goal. Plan pressure belongs in plan settings.
LimitsOne limit card when a limit actually blocks workA permanent credits balance plus a dashed upsell that covers the transcriptKeep the working surface clean.
ShowcaseA weekly Launchpad after PublishCommunity map, events and a partner marketplace as first-class areasThe showcase feeds the builder loop. The rest is a second product.
GitConnect GitHub as one button, with a repo list, and sync in SettingsA separate code area that duplicates gitSpec 055 puts GitHub sync in Settings. One place.
AgentRoutines as a first-run toggle list, a setup checklist, and many channels into one conversation listAn Agent with its own rail and its own navigationOne product, one shell. Channels are transport, not a second app.
AutomationA schedule table with cron, timezone, last run and Run NowPlan gating inside a normal agent answerInspectable automation earns trust. Limits belong in plan screens.
PluginsMost popular plus Apps connected (n) with Active badgesA full-width banner above the listInventory first, marketing second.
MemorySource filters on every memoryNotes, Files, Memory and Data as four top-level destinationsProvenance makes memory trustworthy. Four destinations fragment one context.
Empty statesOne action per empty statePages hidden behind a More menuAn empty state should teach the next step. Every page in one click.
