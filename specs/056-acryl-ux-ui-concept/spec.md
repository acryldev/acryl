# Spec 056: ACRYL UX/UI concept

Status: research. Four established AI app builders, studied from the owner's screenshots, as input for ACRYL's own UX/UI concept (and for spec 055).

The products are named by codename only, here and in every file of this spec:

| Codename | File |
| --- | --- |
| bs44uxui | [design/bs44uxui.html](design/bs44uxui.html) |
| lvbluxui | [design/lvbluxui.html](design/lvbluxui.html) |
| bltuxui | [design/bltuxui.html](design/bltuxui.html) |
| pluxui | [design/pluxui.html](design/pluxui.html) |

Each design file is a Lavish (`npx -y lavish-axi <file>`) mockup that redraws the product's screens and flows in neutral styling (no logos, no brand
names, no copied artwork), followed by what ACRYL should take from it, what it should not, and how it maps to ACRYL today. Source screenshots stay in
the owner's private research folder and are not copied here.
