# @acryldev/create-blends 1.7.13

Released 2026-11-21 with @acryldev/blends 1.7.13.

- An app made from a registry Blend (`--from acrylblends.notes`) or a GitHub repository (`--from github:ana/notes#v0.2.0`) records it in its
  `blend.yaml` as `metadata.from`, so `npx acrylblends update` can bring that source's newer releases in later.
