# create-acrylblends 1.5.4

Asks for [acrylblends 1.5.4](acrylblends-1.5.4.md).

- An app made from a registry starter (`--from <id>`) that has no `plugin-share` row gets the plugin, mounted, so pulling and publishing plugins
  work in it from its first start. Checked with `acrylblends.small-crm`: `plugin list` and `plugin pull github:inboxxobni/hello-cycle@0.1.0`.
