# acrylblends 1.5.11

- `acrylblends update` brings the newer registry release of the Blend an app was made from (its `blend.yaml` id and version) into the app, keeping your changes. It is a git merge: a file only the Blend changed takes the Blend's change, a file only you changed keeps yours, and changes to different parts of one file are both kept. Uncommitted work is committed first. When you and the release changed the same lines, nothing changes and the files are named. `--check` only says whether there is a newer release. ACRYL Control Center shows "Update to x.y.z" on an app when there is one and runs this command.
- A packed product (ACRYL Control Center, ACRYL ADE, any Blend packed with `scripts/pack-blank-mac.mjs`) updates itself: "Check for Updates..." in the app menu, plus a quiet check after start, offers the Blend repository's newer GitHub release. It downloads this machine's installer, checks its SHA-256 against the digest GitHub publishes, and installs it in place: the bundle is swapped on macOS, and the NSIS installer runs silently on Windows. Then the app restarts. Your apps and their data stay where they are.
