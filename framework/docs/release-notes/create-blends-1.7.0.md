# @acryldev/create-blends 1.7.0

The scaffolder publishes in the scope as `@acryldev/create-blends`: run it as `npm create @acryldev/blends my-app` (or the short
`npm create acrylblends my-app`, which is the same tool through a thin alias at the same version). It depends on `@acryldev/blends` at exactly this
version, and apps it makes depend on `"@acryldev/blends": "^1.7.0"`.
