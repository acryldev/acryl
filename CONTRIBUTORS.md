# Contributors

ACRYL is built in the open. Every issue report and pull request is real project
work — welcome at any experience level. This file is the standing contributor
record, newest first. For the live list, see the
[GitHub contributors page](https://github.com/acryldev/acryl/graphs/contributors).

The maintainer rule: reports and PRs are real project work, even when a patch
has to be narrowed, delayed, or reworked before it lands. Credit stays visible
in the commit history, release notes, and this file.
