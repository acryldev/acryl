# @acryldev/app-settings

Validated settings per namespace in one YAML file in the app's home: defaults, base and stored layers, watch, update.

## Install

```sh
npm install @acryldev/app-settings
```

It is a Cordis plugin: its peer dependency is `@deepseek-ai/cordis`, and an app registers it as a row of its `blend.yaml`.
