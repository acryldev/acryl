# @acryldev/builder

The agent's tools for building the app it runs in: write, install, read, list and remove extensions, with real results.

## Install

```sh
npm install @acryldev/builder
```

It is a Cordis plugin: its peer dependency is `@deepseek-ai/cordis`, and an app registers it as a row of its `blend.yaml`.
