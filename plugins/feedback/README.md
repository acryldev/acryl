# @acryldev/feedback

Feedback from the people who use the app: a Feedback button on every page, in production too, that lets them pinpoint the element they mean (or choose "Nothing specific") and send a note; the ACRYL frame shows the notes in the builder's left panel.

## Install

```sh
npm install @acryldev/feedback
```

It is a Cordis plugin: its peer dependency is `@deepseek-ai/cordis`, and an app registers it as a row of its `blend.yaml`.
