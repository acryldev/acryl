# @acryldev/instance

Where the app keeps things (home, port, run lock), chosen once from the environment or the project folder.

## Install

```sh
npm install @acryldev/instance
```

It is a Cordis plugin: its peer dependency is `@deepseek-ai/cordis`, and an app registers it as a row of its `blend.yaml`.
