# @acryldev/agent

An offline agent: deterministic model, tools, memory, and a child fiber per run that holds the run's step budget.

## Install

```sh
npm install @acryldev/agent
```

It is a Cordis plugin: its peer dependency is `@deepseek-ai/cordis`, and an app registers it as a row of its `blend.yaml`.
