# acryl-mount-anchors

Visual mount-anchor inspector (spec 039-visual-mount-anchors, Scope A): point at ACRYL's own running UI, click an element, resolve it to its real Cordis slot and source file

Part of [ACRYL](https://github.com/acryldev/acryl) (`plugins/acryl-mount-anchors`). `pnpm test` in this folder runs its suite.
