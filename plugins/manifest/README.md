# @acryldev/manifest

The app as data: blend.yaml lists ordered plugin rows with config, parameters and on/off switches; validated, composed and locked.

## Install

```sh
npm install @acryldev/manifest
```

It is a Cordis plugin: its peer dependency is `@deepseek-ai/cordis`, and an app registers it as a row of its `blend.yaml`.
