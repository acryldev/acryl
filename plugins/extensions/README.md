# @acryldev/extensions

Install, update, remove and reload plugins while the app runs; a failed update brings the previous version back; a ledger of every change.

## Install

```sh
npm install @acryldev/extensions
```

It is a Cordis plugin: its peer dependency is `@deepseek-ai/cordis`, and an app registers it as a row of its `blend.yaml`.
